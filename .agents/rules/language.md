# Project Language and Communication Rules

## Code and Artifact Language
- **All source code, comments, documentation, Terraform files, variable descriptions, output descriptions, and READMEs MUST be written in ENGLISH.**
- System prompts, configuration scripts, and code examples within repository artifacts must also be written in English.

## User Communication Language
- **All chat responses, explanations, user interaction, and progress updates with the user MUST be in SPANISH.**
